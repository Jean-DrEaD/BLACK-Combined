# BLACK Combined

Recomp de **BLACK (Xbox, 2006)** para PC, reunindo o upstream
[portingpete/Black-2006-Recomp](https://github.com/portingpete/Black-2006-Recomp)
com melhorias da comunidade.

> ⚠️ Este repositório **não contém o jogo**. É necessário o disco original do Xbox.

## Recursos
- Correr / pular
- Legendas in-game
- Câmera livre
- AO e reflexos
- Hold-to-aim
- PT-BR

## Requisitos
- Windows 10/11 x64
- Disco/ISO original de BLACK (`default.xbe` SHA-256 `DF2739C3...68F6`)

## Como usar
1. Baixe o *starter* em [Releases](../../releases).
2. Extraia e execute **`Build BLACK.cmd`**.
3. Selecione seu disco/ISO quando solicitado.
